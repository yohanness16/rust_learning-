### what is cargo !

cargo is a build tool for rust 
it comes with rust and use to build , install dependencies and so on 

to check whether cargo is installed in ur machine check using this cmd 

cargo --version

if succefully installed u will see a message like this

cargo 1.94.0 (85eff7c80 2026-01-15)

if not check the offical documentation to install it 

to create a rust project with cargo run the following 

cargo new "your_desired_name_here"

for example 
cargo new hello 

create a folder with rust code

then cd hello 

in there there is a cargo.toml file and a srs folder
if there is git initated in the parrent folder a git ignore will not created in the hello folder to overide this we can use the flag vcs 

run the following cmd 

cargo new hello --vcs=git 

to now more lest use cargo new --help

### building with cargo 
in the folder we created hello in terminal write the following 

--cargo build 

new folder is created and also a file named cargo.lock is created 

the target folder have our excutable file with other files and folders 
the excutable file is found in /Target/debug/hello

we can run it with command ./target/debug/hello

and it will print out the message hello world 

the cargo.lock have the track of dependencies used 

we can also run with
--cargo run 

### checking 

we can run 
--cargo check to check if the project will compile without producing excutable file 

last but not least we will see release 

cargo build have a relese mode in which we use to relese the final version or ship ready version of the project 
command 
cargo build --release 
will create the excutable file in the release folder rather than the debug folder 
we can run using cargo run --release or ./target/release/hello
