### variables in rust 
variables are a namespace in which hold some value 
for example instead of writing 
fn main (){
    50
}

in this case 50 just dont represent any thing what is 50

but 
fn main (){
    let price : i32 = 50 ;
}

now 50 represent a price

variables are immutable by default which means the value of the variable cant be change 

for example 
fn main (){
    let s : i32 = 25;
    println!(" the length of the table is {s} centimeters );

    s = 10;  /// will cause an error saying 


}
in this example the variable s is immutable by default so when we reassign to 10 the compiler will throw and error

### THE mut Keyword

is used to make a variable mutable for example

fn main (){
    let mut s : i32 = 25;
    println!("the length of the table is {s} centimeters");
    s : i32 = 10;
    println!("the value of the table is {s} centimeters");
}
