### variable shadowing

is a way of declaring same varible again with different data type 
we use the let keyword again when we declare the iable again 
no mut required 
the first value declared is no longer used 

example

fn main (){

    let size : &str = "10.05" ;
    println!("{size}");

    let size :f64 = 10.05;
    println!("{size}");

    let size : i32 = 10;
    println!("{size}");
}

the code output will be 
10.05
10.05
10

why??
because we have shadowed it so the size virible works in the scop from its declaration to its next declaration 
after that it will no longer be the first one 


### scope of a variable 

scope of the varibleiable indicate the life of the variable or the block in which the varibale is valid 
for example if i have this code 

fn main () {
    let x : i32 = 100;
    println!("{x}");
}

println!("{x}");

in the main function the x will be printed but outside it the print will be error cause no varible named x in its scope

scope of a varible is defined by the block in which it is located 
block is defined by curly braces 
for example :
fn main (){
    let x : i32 = 100;
    println!("{x}");
    {
        let x : i32 = 150;
        println!("{x}");
    }
    println!("{x}");
}


the output will be 
100
150
100

causee the first one is in main scope so the x is 100
the second print is in its scop and x is 150
the third print is in the main scop and x is 100 in main scop 


program can access varible in the above scope but not in lower 

example :
fn main (){
    let x : i32 = 100;
    {
        println!("{x}");
    }
}

will print the value of x as 100

but 
fn main (){
    {
        let x : i32 = 100;
    }

    println!("{x}");
}

will result in compile error 


 
### the const keyword and constants 

constants are like varibe a name for some value but once cant change delared cant be change even with the mut 

constant differ from variables by 3 things 

    1. constants are injected in the program in compile time while varibles are processed in run time
        so if our constant have no file the program will crash 
    2. constants can be accessed from file level fro out of scop but varibles need to be defiend in sma scop or parrent scope to be accessed

    3. we need to hardkly define the data type by using : in constant while in varible the rust will add when we declare the value
